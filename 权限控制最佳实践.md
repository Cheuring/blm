# 微服务权限控制最佳实践指南

## 1. 后续模块权限实现步骤

当你需要为新的模块（如商家服务、订单服务等）添加权限控制时，请按照以下步骤：

### 第一步：引入依赖
在新服务的 `pom.xml` 中添加：
```xml
<dependency>
    <groupId>com.blm</groupId>
    <artifactId>common</artifactId>
    <version>1.0.0</version>
</dependency>
```

### 第二步：配置切面扫描
在主启动类上添加：
```java
@SpringBootApplication
@ComponentScan(basePackages = {
    "com.blm.merchant",  // 当前服务包
    "com.blm.common"     // 公共模块包，包含AuthorizationAspect
})
public class MerchantServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(MerchantServiceApplication.class, args);
    }
}
```

### 第三步：在Controller中使用权限注解
```java
@RestController
@RequestMapping("/api/merchants")
public class MerchantController {
    
    // 示例：只有商家角色可以访问
    @GetMapping("/store/info")
    @RequireRole(value = {"MERCHANT"}, message = "需要商家权限")
    public Result<StoreVO> getStoreInfo(@RequestHeader("X-User-Id") String userId) {
        // 业务逻辑
        return Result.success(storeInfo);
    }
    
    // 示例：管理员或超级管理员可以访问
    @PostMapping("/{merchantId}/approve")
    @RequireRole(value = {"ADMIN", "SUPER_ADMIN"}, logic = "OR", message = "需要管理员权限")
    public Result<Void> approveMerchant(@PathVariable Long merchantId) {
        // 业务逻辑
        return Result.success();
    }
}
```

## 2. 常见权限场景的处理方式

### 2.1 多角色用户处理
```java
// 场景：用户既是普通用户又是商家，访问不同功能
@GetMapping("/orders")
@RequireRole(value = {"USER", "MERCHANT"}, logic = "OR")
public Result<List<OrderVO>> getOrders(
    @RequestHeader("X-User-Id") String userId,
    @RequestHeader("X-User-Roles") String userRoles,
    @RequestParam(value = "viewAs", required = false) String viewAs) {
    
    List<String> roles = Arrays.asList(userRoles.split(","));
    
    if ("merchant".equals(viewAs) && roles.contains("MERCHANT")) {
        // 以商家身份查看订单
        return Result.success(orderService.getMerchantOrders(userId));
    } else if (roles.contains("USER")) {
        // 以用户身份查看订单
        return Result.success(orderService.getUserOrders(userId));
    }
    
    throw new PermissionDeniedException("无权限查看订单");
}
```

### 2.2 资源所有权验证
```java
// 场景：商家只能管理自己店铺的商品
@PutMapping("/products/{productId}")
@RequireRole(value = {"MERCHANT"}, message = "需要商家权限")
public Result<Void> updateProduct(
    @RequestHeader("X-User-Id") String userId,
    @PathVariable Long productId,
    @RequestBody ProductUpdateDTO dto) {
    
    // 验证商品是否属于当前商家
    Product product = productService.getById(productId);
    if (!product.getMerchantId().equals(Long.valueOf(userId))) {
        throw new PermissionDeniedException("无权限修改该商品");
    }
    
    productService.updateProduct(productId, dto);
    return Result.success();
}
```

### 2.3 条件权限控制
```java
// 场景：只有在营业状态的商家才能接单
@PostMapping("/orders/{orderId}/accept")
@RequireRole(value = {"MERCHANT"}, message = "需要商家权限")
public Result<Void> acceptOrder(
    @RequestHeader("X-User-Id") String userId,
    @PathVariable Long orderId) {
    
    // 检查商家营业状态
    Merchant merchant = merchantService.getById(Long.valueOf(userId));
    if (!merchant.isOpen()) {
        throw new BusinessException("店铺未营业，无法接单");
    }
    
    orderService.acceptOrder(orderId, Long.valueOf(userId));
    return Result.success();
}
```

## 3. 权限控制的进阶用法

### 3.1 自定义权限验证逻辑
```java
// 创建自定义权限注解
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface RequireStoreOwner {
    String message() default "需要店铺所有者权限";
}

// 对应的切面
@Aspect
@Component
public class StoreOwnerAspect {
    
    @Around("@annotation(requireStoreOwner)")
    public Object checkStoreOwner(ProceedingJoinPoint joinPoint, RequireStoreOwner requireStoreOwner) throws Throwable {
        HttpServletRequest request = ((ServletRequestAttributes) RequestContextHolder.currentRequestAttributes()).getRequest();
        String userId = request.getHeader("X-User-Id");
        
        // 从方法参数中获取storeId
        Object[] args = joinPoint.getArgs();
        Long storeId = extractStoreId(args);
        
        // 验证是否为店铺所有者
        if (!merchantService.isStoreOwner(Long.valueOf(userId), storeId)) {
            throw new PermissionDeniedException(requireStoreOwner.message());
        }
        
        return joinPoint.proceed();
    }
}
```

### 3.2 动态权限控制
```java
// 基于数据库的动态权限配置
@Service
public class DynamicPermissionService {
    
    @Autowired
    private PermissionRepository permissionRepository;
    
    public boolean hasPermission(Long userId, String resource, String action) {
        List<Permission> userPermissions = permissionRepository.findByUserId(userId);
        
        return userPermissions.stream()
            .anyMatch(p -> p.getResource().equals(resource) && 
                          p.getAction().equals(action) &&
                          p.isActive());
    }
}

// 在控制器中使用
@PostMapping("/sensitive-operation")
@RequireRole({"ADMIN"})
public Result<Void> performSensitiveOperation(@RequestHeader("X-User-Id") String userId) {
    
    // 额外的动态权限检查
    if (!dynamicPermissionService.hasPermission(Long.valueOf(userId), "SYSTEM", "MODIFY")) {
        throw new PermissionDeniedException("缺少系统修改权限");
    }
    
    // 执行敏感操作
    return Result.success();
}
```

### 4.2 批量权限验证
```java
// 对于需要验证多个资源权限的场景
@PostMapping("/batch-operations")
@RequireRole({"MERCHANT"})
public Result<Void> batchUpdateProducts(
    @RequestHeader("X-User-Id") String userId,
    @RequestBody List<ProductUpdateDTO> products) {
    
    // 批量验证所有商品的所有权
    List<Long> productIds = products.stream().map(ProductUpdateDTO::getId).collect(Collectors.toList());
    List<Product> existingProducts = productService.getByIds(productIds);
    
    boolean allOwned = existingProducts.stream()
        .allMatch(p -> p.getMerchantId().equals(Long.valueOf(userId)));
    
    if (!allOwned) {
        throw new PermissionDeniedException("存在无权限修改的商品");
    }
    
    productService.batchUpdate(products);
    return Result.success();
}
```

## 5. 安全最佳实践

### 5.1 敏感操作的二次验证
```java
@PostMapping("/critical-action")
@RequireRole({"ADMIN"})
public Result<Void> performCriticalAction(
    @RequestHeader("X-User-Id") String userId,
    @RequestParam("verificationCode") String verificationCode) {
    
    // 验证二次确认码
    if (!verificationService.validateCode(Long.valueOf(userId), verificationCode)) {
        throw new SecurityException("验证码错误");
    }
    
    // 记录操作日志
    auditService.logCriticalAction(Long.valueOf(userId), "CRITICAL_ACTION");
    
    // 执行关键操作
    return Result.success();
}
```

### 5.2 权限变更审计
```java
@PostMapping("/users/{targetUserId}/roles")
@RequireRole({"SUPER_ADMIN"})
public Result<Void> changeUserRole(
    @RequestHeader("X-User-Id") String adminId,
    @PathVariable Long targetUserId,
    @RequestParam String newRoles) {
    
    // 记录变更前的状态
    List<String> oldRoles = userService.getUserRoles(targetUserId);
    
    // 执行角色变更
    userService.updateUserRoles(targetUserId, newRoles);
    
    // 记录审计日志
    AuditLog log = AuditLog.builder()
        .operatorId(Long.valueOf(adminId))
        .targetUserId(targetUserId)
        .action("ROLE_CHANGE")
        .oldValue(String.join(",", oldRoles))
        .newValue(newRoles)
        .timestamp(LocalDateTime.now())
        .build();
    
    auditService.saveLog(log);
    
    // 清除相关缓存
    permissionService.clearUserRoleCache(targetUserId);
    
    return Result.success();
}
```

## 6. 错误处理和用户友好提示

### 6.1 详细的错误响应
```java
@ExceptionHandler(PermissionDeniedException.class)
public Result<Void> handlePermissionDenied(PermissionDeniedException e, HttpServletRequest request) {
    String userId = request.getHeader("X-User-Id");
    String userRoles = request.getHeader("X-User-Roles");
    
    log.warn("权限不足 - 用户ID: {}, 角色: {}, 错误: {}, 请求路径: {}", 
             userId, userRoles, e.getMessage(), request.getRequestURI());
    
    // 根据不同场景返回不同的错误信息
    String userFriendlyMessage = generateUserFriendlyMessage(e.getMessage(), userRoles);
    
    return Result.error(ResultCode.PERMISSION_DENIED, userFriendlyMessage);
}

private String generateUserFriendlyMessage(String originalMessage, String userRoles) {
    if (userRoles == null || userRoles.isEmpty()) {
        return "请先登录";
    }
    
    if (originalMessage.contains("MERCHANT")) {
        return "此功能仅限商家使用，如需开通商家权限请联系客服";
    } else if (originalMessage.contains("ADMIN")) {
        return "此功能仅限管理员使用";
    }
    
    return "权限不足，无法执行此操作";
}
```
